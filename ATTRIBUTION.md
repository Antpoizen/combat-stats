# Source and attribution

Based on **Combat Stats v4.0.0** by **Smantella** (https://github.com/Smantella/combat-stats), licensed CC BY-SA 4.0 per its shipped module manifest. We preserved the UI charts, CSS, localization, settings forms, summary presentation and source exporter interface, replacing its D&D5e/Midi-QOL tracker with a PF1e resource observer and local chart/spreadsheet renderers.

Third-party data/tool authors **Nevela**, **Foundry PF1e maintainers**, and the user's custom **Armor Soak Pool** are not part of this distribution; no code from those modules is redistributed here. Their names are used for compatibility descriptions only.
